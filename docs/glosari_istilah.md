# Glosari Istilah Pengaturcaraan & Sains Komputer MELAYU

Glosari ini menyediakan rujukan istilah teknikal sains komputer dan pengaturcaraan dalam laras bahasa Melayu serumpun.

| Istilah Bahasa Melayu | Istilah Bahasa Inggeris | Maksud & Huraian Ringkas |
|---|---|---|
| **Pembolehubah** | *Variable* | Ruang simpanan data boleh ubah (`ada`). |
| **Pemalar** | *Constant* | Nilai malar kekal yang tidak boleh ditulis ganti (`tetap`). |
| **Lelaran / Gelung** | *Loop / Iteration* | Pengulangan blok arahan (`selagi`, `untuk`). |
| **Fungsi / Kerja** | *Function* | Blok logik boleh guna semula dengan nilai pulangan (`kerja`, `pulang`). |
| **Penutupan** | *Closure* | Fungsi yang memegang dan mengingat persekitaran skop induknya. |
| **Rekursi** | *Recursion* | Fungsi yang memanggil dirinya sendiri sehingga kes dasar dicapai. |
| **Kelas** | *Class* | Acuan atau templat struktur objek berorientasi (`kelas`). |
| **Pembina** | *Constructor* | Fungsi khas yang membina dan menetapkan sifat awal instans (`bina`). |
| **Instans / Objek** | *Instance / Object* | Wujud fizikal dalam memori yang dijana daripada sesebuah kelas. |
| **Rujukan Diri** | *Self / This* | Penuding rujukan kepada instans objek semasa (`diri`). |
| **Pewarisan** | *Inheritance* | Mekanisme mewarisi kaedah dan sifat daripada kelas induk (`warisi`). |
| **Rujukan Induk** | *Super* | Penuding rujukan kepada pembina atau kaedah kelas induk (`induk`). |
| **Polimorfisme** | *Polymorphism* | Keupayaan kaedah yang sama bertindak berbeza mengikut kelas anak. |
| **Timbunan** | *Stack (LIFO)* | Struktur data masuk kemudian keluar dahulu. |
| **Giliran** | *Queue (FIFO)* | Struktur data masuk dahulu keluar dahulu. |
| **Kotak Pasir** | *Sandbox* | Benteng keselamatan yang mengehadkan akses fail dan sistem hos. |
| **Limpahan Tindanan** | *Stack Overflow* | Ralat akibat pemanggilan fungsi rekursif melampaui had memori. |

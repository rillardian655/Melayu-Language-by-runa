# 📁 Contoh Program MELAYU (.ml)

Direktori ini mengandungi pelbagai contoh atur cara yang ditulis menggunakan bahasa pengaturcaraan **MELAYU**.

## Senarai Contoh

| Fail | Penerangan | Konsep Digunakan |
|---|---|---|
| `hello.ml` | Program asas "Hello World" | `tunjuk` |
| `fizzbuzz.ml` | Algoritma klasik FizzBuzz | `untuk ... dari ... hingga`, `jika`, `modulo` |
| `kalkulator.ml` | Kalkulator empat operasi asas | `kerja`, `pulang`, `cuba ... tangkap` |
| `fibonacci.ml` | Kiraan jujukan Fibonacci | Fungsi rekursif |
| `tebak_angka.ml` | Permainan teka nombor interaktif | `rawak()`, perbandingan |
| `sintaks_lengkap.ml` | Demonstrasi semua ciri sintaks v0.1.0 | Koleksi, gelung, kamus, pengendalian ralat |
| `keselamatan_dan_fail.ml` | Demo keselamatan & sandbox operasi fail v0.1.1 | `rawak()`, `tulisFail()`, `bacaFail()`, anti-traversal |
| `matematik_modul.ml` | Modul contoh fungsi pengiraan dan pemalar | Modul pustaka yang boleh diimport |
| `demo_modul.ml` | Demo sistem import modul & alat koleksi lanjutan v0.1.2 | `ambil`, `.pecah()`, `.isih()`, `.cantum()`, `.ganti()` |
| `pemprosesan_data_dan_json.ml` | Demo pemprosesan data fungsian, enjin JSON & masa v0.2.0 | `bacaJSON`, `tulisJSON`, `.petakan()`, `.tapis()`, `.kiraSemua()`, `tarikhKini()` |
| `oop_kelas_dan_objek.ml` | Demo Pengaturcaraan Berorientasikan Objek (OOP) v0.3.0 | `kelas`, `bina`, `diri`, `warisi`, `induk`, pewarisan & sifat dinamik |
| `struktur_data.ml` | Implementasi struktur data timbunan (stack) & giliran (queue) | OOP, `.tambah()`, `.buang()`, LIFO & FIFO |
| `algoritma_isih.ml` | Isihan buih (Bubble Sort) & isihan pantas rekursif (QuickSort) | Pengisihan data, lelaran bersarang, rekursi |
| `rekursi_menara_hanoi.ml` | Penyelesaian teka-teki klasik Menara Hanoi | Rekursi tiga tiang, penjejakan langkah |
| `sistem_perbankan.ml` | Simulasi sistem transaksi bank pelbagai akaun | Pewarisan `AkaunBank` ke `AkaunSimpanan` |
| `matematik_vektor.ml` | Kelas matematik vektor 2D dengan magnitud & darab bintik | Vektor fizik, `puncaKuasaDua()`, dot product |
| `carian_binari.ml` | Algoritma carian binari O(log n) lelaran | Carian pintar pada senarai berisih |
| `penyulitan_caesar.ml` | Kriptografi klasik penyulitan dan nyahsulit Caesar | Manipulasi aksara rentetan, modulo 26 |
| `kiraan_matriks.ml` | Operasi matriks 2D, penentu (det) & transposisi | Struktur kelas matematik berbilang dimensi |
| `sistem_inventori.ml` | Sistem pengurusan inventori kedai & stok produk | OOP pengurusan nilai dan kiraan baki stok |
| `generator_kata_laluan.ml` | Penjana kata laluan rawak selamat berasaskan entropi | `rawak()`, gabungan simbol dan huruf |
| `pengesah_borang.ml` | Pengesah borang data input pendaftaran pengguna | Pengesahan format emel, panjang minimum |
| `analisis_teks.ml` | Analisis kekerapan perkataan dalam perenggan | `kamus`, `.pecah()`, `.adaKunci()` |
| `pola_rekabentuk_pemerhati.ml` | Pola reka bentuk pemerhati (Observer / Pub-Sub) | Pemancaran acara kepada berbilang pelanggan |
| `pola_rekabentuk_kilang.ml` | Pola reka bentuk kilang (Factory Pattern) | Penjanaan objek notifikasi dinamik mengikut jenis |
